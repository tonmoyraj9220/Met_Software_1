**Welcome to my text-based adventure game, "Nature Rescue".**

This game was made using python and is about a sea-side fishing village where fish are dying in the bay and found washed-up on the shore. While investigating you find out that this is being caused by logging in the forest which is polluting the river in turn killing the fish.
The village fishing festival is also coming up in a month, now you must resolve this issue before the festival.
Now there are three ways the crisis can be averted, test the water from the riven get proof of the pollution and get proof an endangered species of owl living in the forest then submit the proof to the village council in the Townhall to force the company to stop their logging operations. Or gather the villagers tell them about the issue, file petition to the village council and stop the cutting down of trees in the forest. Or you could the replant trees in the clearing you found and put in a filtering net so that the ocean water isn’t polluted any further and save the fish from dying.

*Requirements-*
This game runs in VS Code Python terminal. So, you need to install-
1.  VS Code - https://code.visualstudio.com/Download?_exp_download=d53503e735
2.  Python 3 - https://www.python.org/downloads/
3.  Python debugger extension for VS Code from exxtensions in VS Code.

*Setting-up to play*
1.  Download of clone the game from the repository.
2.  Open VS Code and open the game folder in VS Code.
3.  Now open the main.py file in VS Code and press the run python file button
    found on the  top right corner in VS Code which look like a play button.
4.  Don't worry if you can't find the run button, first you have to mark the
    folder as trusted.
